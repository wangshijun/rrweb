# Tooling and Extensions

In addition to the core libraries, the rrweb ecosystem provides tools and browser extensions to simplify and enhance your workflow. These utilities allow you to perform common tasks, such as recording sessions without writing code or converting session data into standard video files, with minimal setup.

This section provides an overview of the available tools. For detailed instructions, please refer to the specific sub-pages.

<x-cards>
  <x-card data-title="Web Extension" data-icon="lucide:mouse-pointer-click" data-href="/tooling-and-extensions/web-extension">
    Record and replay user sessions directly from your browser with a convenient extension, eliminating the need for any code integration on the target website. It is available for both Chrome and Firefox.
  </x-card>
  <x-card data-title="Video Conversion (rrvideo)" data-icon="lucide:film" data-href="/tooling-and-extensions/video-conversion">
    A command-line tool that transforms rrweb's JSON-based event streams into standard video formats. This is useful for archiving, sharing, or analyzing sessions using conventional video players.
  </x-card>
</x-cards>
